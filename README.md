# Arkham III Mythos Cup — offline Home Screen web app

Live: **https://alfyburger.github.io/arkham-mythos-cup/**

Open it in Safari on iPhone → Share → **Add to Home Screen**, then open it once from the Home Screen
while online (Options shows "Ready for offline use"). After that it works without internet.

Based on [Arkham III Mythos Cup](https://github.com/mephitrpg/arkham-iii-mythos-cup) by Jure di Mephit
(Apache-2.0), with every expansion always included and the Cordova runtime replaced by `js/platform-shim.js`.

The `ios` branch holds a native iPhone version (Swift wrapper) built into a sideloadable `.ipa` by GitHub Actions.
